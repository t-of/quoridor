# quoridor — 2人で通路を作って陣地を目指す

9x9マスの盤で駒を進めるか壁を置いて相手を妨げ、先に向こう側の端へ着いたら勝ちの陣取りゲーム。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/quoridor/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

9×9 のマスに、自分（下端中央）と相手（上端中央）のコマを置く。手番ごとに「コマを 1 マス動かす」か
「壁を 1 枚置く」のどちらかを行い、先に向こう岸の列に着いたほうが勝ち。

- コマは上下左右に 1 マス進める。壁は越えられない。
- 相手のコマが隣にいれば飛び越せる。飛んだ先が壁や盤外なら、相手の左右（斜め）に移れる。
- 壁は 1 人 10 枚、2 マス分の長さで溝に置く。壁どうしは重ならず、交差もしない。
  どちらのコマにもゴールへの道が 1 本は残る壁しか置けない。
- 操作は「コマモード／壁モード」のボタンで切り替える。コマモードでは動けるマスがハイライトされ、
  タップで移動。壁モードでは縦横を切り替えるボタンがあり、マスの間の溝の交点付近をタップすると
  置ける場所がプレビューされ、同じ場所をもう一度タップすると置く。
- 開始画面で「CPU と対戦」か「2 人で対戦（同じ端末で交代）」を選べる。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```
